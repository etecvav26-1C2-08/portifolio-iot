# portfolio-iot
---
<h1> 👋 Bem-vindo ao portifolio-iot !!</h1>
<p>Este portfólio reúne atividades desenvolvidas por nós na disciplina de Sistemas Embarcados e IOT, utilizando o Arduino e a linguagem C++ como principal ferramenta de aprendizado.

Ao longo dos exercícios, trabalhamos conceitos fundamentais da lógica de programação, e estruturação de montagem de projetos utilizando LED's, sensores e servos motores para montagem de diversos embarcados que podem ajudar na vida das pessoas no dia a dia. Aprendemos a montar, ligar os fios e a lógica necessária para estruturar e montar a programação para o funcionamento de tal sistema.

Além disso, o trabalho em grupo contribuiu para o desenvolvimento da colaboração, troca de conhecimentos e construção conjunta das soluções.

Este portfólio representa nosso aprendizado, dedicação e crescimento na área de programação.</p>
